# 🛡️ Minecraft Bedrock Anti-Cheat

> Anti-cheat for Minecraft Bedrock servers. Currently under development and testing.

## 📖 About the project

I'm currently working on a fairly large anti-cheat for **Minecraft Bedrock** servers.

The idea is to create a system as complete as possible, capable of detecting different types of cheats, unusual behavior, and other things that could affect the experience of players on a server.

The project is still under development and testing, so many things may change as I continue working on it.

For now, this is a personal project and one of the biggest projects I've worked on so far.

## 🚧 Current status

**In development and testing**

The project currently has **106 files** and is still growing as I add new features, detections, and improvements.

There is still quite a lot of work to do, especially when it comes to testing, optimization, stability, and reducing false positives.

## 🔍 Some of the things I'm working on

- Detection of different types of cheats
- Movement checks
- Suspicious behavior detection
- Alert system
- Logging system
- False positive reduction
- Performance and optimization
- Different server protection systems
- Improving and organizing the project structure
- New detections and systems that I will add during development

The list may change quite a bit as the project continues to grow.
